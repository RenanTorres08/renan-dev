
# Renan DEV - Portfólio Pessoal

## Sobre o projeto

Este projeto é um portfólio pessoal criado para apresentar
minhas informações, habilidades e projetos desenvolvidos
durante meus estudos em Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Funcionalidades

- Menu de navegação.
- Apresentação pessoal.
- Seção de projetos.
- Área de contato com GitHub.
- Layout responsivo.
- Animações suaves ao navegar pela página.

## Projetos apresentados

1. Sistema de Consumo de Água.
2. Pesquisa de Satisfação.
3. Sistema de Notas Escolares.

## Recurso adicional

Foi implementada uma animação de entrada utilizando
JavaScript e Intersection Observer, fazendo com que
os elementos apareçam suavemente durante a navegação.
